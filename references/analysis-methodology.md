# 试卷分析方法论（原始 Prompt 的有效萃取）

来源：用户最初的《期中考试考点梳理Prompt.md》。该 Prompt 的多年级合一报告结构与教材知识树阶段与定稿模板不一致，不再采用；以下是其仍然有效、且必须遵守的方法论内核。

## 1. 总体原则

- 以真实材料为依据：考点/题型/分值/频率结论必须由原卷、答案、解析支持；教材只用于确认章节归属与概念定义。
- 严格区分：已考查事实 / 统计规律 / 备考推断。不得把高频等同于必考，不得声称能预测命题。
- 资料缺信息（地区/版本/范围/满分）标记"未知/待确认"，不得编造；无法支持的统计记缺失，不虚构补全。
- 考试范围不同的试卷独立分组（年级 × 教材版本 × 地区 × 考试范围），禁止混合统计口径。
- 尚未进入考试范围的知识点不得因其他年级学过就纳入。

## 2. 逐题数据库字段（build_db.py 的理论依据）

每题至少记录：试卷编号、题号、原始题意（完整保留条件）、题型、分值（原卷明确标注的）、章节、一级/二级/辅助考点、考查能力、主要解法、标准答案、核心步骤、易错位置、难度（基础/较易/中等/较难/压轴）、证据定位（文件+题号）、可信度。

- 一题多考点时记主考点 + 辅助考点，不强行归一。
- score 允许 None：题组总分已知但逐题未标注时如实记录，禁止虚构逐题分值或把整组分值重复计入每题。
- 答案核验：已知条件/图形/单位完整性、答案与题对应、解析推导正确、疑似印刷错误标记"待核实"、注意容易忽略的限制条件（增根、非零、偶次幂）。
- 规范化分类：统一同一知识点的不同表述；既不把本质相同的考题拆成不同类别，也不把需要不同能力的题合并成笼统类别。

## 3. 统计口径

- 试卷覆盖率 = 出现该知识点的独立试卷数 ÷ 纳入统计的独立试卷总数 × 100%（同一卷多次出现只计一次卷）。
- 分值占比用"可确认分值 ÷ 满分"；无法拆分的多章节综合题保留总分并标记跨章节，不得重复累加到每个知识点。
- 满分不同的卷比较分值占比而非原始分。
- 小样本必须标注"样本较少，仅供参考"；区分明确值/估算值/缺失值，不制造虚假精确。
- 输出优先级分层：优先掌握 / 重点训练 / 综合提升 / 补充了解，并说明分类依据。

## 4. 选择题专项要点

- 统计：数量、分值、高频考点、章节分布。
- 干扰选项五列表：选项 / 是否正确 / 对应判断 / 错误思路 / 识别方法；解释每个干扰项"为什么有迷惑性"；禁止杜撰原题选项。
- 策略附适用条件：直接计算、特殊值、代入验证、排除法、数形结合、分类讨论、定义直接判断——不把技巧包装成万能捷径。
- 每种高频题型给 1 道原题完整拆解 + 策略，模板见 report-template.md。

## 5. 填空题专项要点

- 题型分布表 + 末段（第 14—19 题级别的难题带）单独盘点。
- 每类考点给：题型名、章节知识点、代表原题（完整）、答案与关键推导、考查能力、基础方法、常见错误及原因、其他考查形式。
- 隐蔽陷阱检查方向（按年级实际筛选，不硬塞）：概念偏差、条件遗漏、特殊情况未考虑、多解无解被忽略、符号与运算顺序、单位范围精度格式、图形读取错误、必要/充分条件混淆、思维定式。
- 陷阱条目必须配真实原题（报告 3.3 的格式）。

## 6. 压轴题要点

- 识别：位置 + 分值占比 + 小问数 + 知识点组合 + 推理深度；无法确认时标"末题/综合题候选"。
- 按真实样本建立压轴分类体系（七年级案例：面积/体积"算两次"→ 恒等式 → 迁移应用，8/14 卷出现）。
- 分析小问递进：前问是否为后问铺垫/提供结论、是否独立、是否有隐藏限制条件。
- 每道典型题写：第一眼识别什么、核心条件、该联想的定理、推理路径、最易卡住的步骤、替代思路、前置知识。
- 变式分层：基础变式 → 条件变式 → 结构变式 → 综合变式 → 拓展变式；不适配就不硬凑五层。

## 7. 易错点要点

- 具体到数学思维与计算步骤，禁止"粗心"归因。
- 每条输出：名称、章节知识点、典型错误表现、错误原因、正确思路、所需概念公式、规避检查步骤、真实证据、巩固练习方向。
- 区分"原卷证实"与"潜在风险"两种证据等级。

## 8. 变式题（AI 原创）要点

- 选题：多卷重复考点、基础性知识点、易错题型、可多角度考查的题、有代表性的压轴。
- 变化方式：数值/条件/设问/正逆互换/特殊↔一般/背景/图形/单点↔组合/增设易忽略限制。
- 每题必含：编号、章节、核心知识点、难度、原题来源与编号、变式方式、完整题目、标准答案、详细解析、关键步骤、易错点、出题意图。
- 与原题联系弱的标注"同考点原创题"，不强行称变式。
- 质量检查 8 项（见 format-rules.md §四），未通过不进题库。
