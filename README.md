# math-exam-review-report · 初中数学考点梳理报告生成 Skill

一个经过真实项目全流程验证的 **Agent Skill**：给它一个年级的一批期中/期末数学试卷（原卷 + 解析版 docx），它按固定流水线产出一份可直接印发给学生的 **Word 考点梳理报告**（LaTeX 公式原生排版）+ 逐题数据库。

首个落地案例（也是本 Skill 的模板来源）：**《七年级期中考点梳理报告》**（14 份试卷 · 397 题逐题分析），定稿样例见 [`七年级期中考点梳理报告.docx`](./七年级期中考点梳理报告.docx)。

## 产出物

| 文件 | 说明 |
|---|---|
| `{年级}{考型}考点梳理报告.docx` | 七大部分结构的 Word 复习报告，公式全部为 OMML 原生公式（源自 LaTeX），页眉「Oli教室专用」 |
| `questions.csv` | 逐题数据库：卷名/题号/题型/分值/考点编码/难度/易错点 |
| `stats.json` | 考点覆盖率、难度分布、高频题型等统计（报告中的频次结论全部可追溯到它） |

只产出 Word，不维护 PDF。

## 工作流程（五阶段）

1. **Stage 0 · 资料清点与格式转换**：给每份卷分配内部编号 T01…，pandoc 批量转 Markdown 并 `--extract-media` 提取题图；考试范围不同的卷单独分组。
2. **Stage 1 · 逐题数据库**：逐卷逐题人工判读录入（题号/题型/分值/考点/难度），按年级重定义考点编码体系，生成 `questions.csv` + `stats.json`。
3. **Stage 2 · 撰写内容源**：`review_content.md`，七部分结构（知识总览 → 选择题专项 → 填空题专项 → 压轴拆解 → 跨卷母题 → 易错清单 → AI 变式题库）；每道引用真题执行"三查"：题号核对、题干选项完整（图片公式必须读图转写）、答案重算。
4. **Stage 3 · Word 生成**：`pandoc -t docx`（LaTeX → OMML）+ `style_docx.py` 后处理。
5. **Stage 4 · 质检硬闸门**：10 项清单全过才交付（公式 `$` 配对、禁用字面 grep 归零、TXX 编号残留、图片/公式数量核对、页眉存在……）。

详细执行说明见 [`SKILL.md`](./SKILL.md)。

## 复用到其他年级

需要替换的只有四样：**试卷文件夹、PAPERS 卷名映射与分组、年级考点编码体系、内容源正文**。格式规则、模板、脚本、质检清单全部直接复用。

## 设计原则（特色）

- **错误档案驱动**：`references/format-rules.md` 记录了开发过程中真实犯过的 13 类错误（Unicode 上标糊弄公式、PDF 反复返工、选项图片丢失、TXX 编号让学生看不懂、"附原题"之类元信息混入正文……），每条含用户原话反馈与修正方案，用于防止 AI 交接后重蹈覆辙。
- **结论可追溯**：一切"高频/必考"表述必须能回溯到逐题数据库与原卷题号；区分"已考查事实 / 统计规律 / 备考推断"。
- **学生视角**：正文引用一律"卷名 + 题号"，讲考点必附完整原题（题目与答案分段），正文零元信息。
