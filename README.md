# math-exam-review-report

> 面向初中数学期中/期末复习的 **考点梳理报告自动生成技能**（Agent Skill）。
>
> 从逐题数据库建立、真题图片公式读图转写、LaTeX 公式 Word 原生排版，到引用规则与交付前质检闸门——一条龙产出可直接印发给学生的复习报告，且全部频次结论可追溯。

## ✨ 这是什么

`math-exam-review-report` 是一个 Agent Skill（智能体技能包），把一次完整的考点梳理报告制作流程沉淀为可复用的工作流与踩坑经验。它解决的问题非常具体：

- 一批期中试卷散落在手里，哪些考点高频、哪些陷阱必考，靠人工翻卷既慢又容易数错；
- 试卷里的公式大量是**图片**，直接复制会丢，直接跳过会让学生"还要去原卷看原题"；
- 市面上常见的"复习资料"充斥版本号、排版说明、方法论免责句等元信息，学生根本不需要看这些。

本技能将整个流程标准化：**逐题判读入库 → 按定稿模板撰写 → pandoc 生成 Word（公式转 OMML 原生排版）→ 质检闸门**，并把开发过程中真实犯过的 13 类错误连同用户反馈一并沉淀为错误档案，防止 AI 交接后重蹈覆辙。

首个落地案例（本技能的模板来源）：**《七年级期中考点梳理报告》**——14 份试卷 · 397 题逐题分析，定稿样例见 [`七年级期中考点梳理报告.docx`](./七年级期中考点梳理报告.docx)。

当你的任务符合以下画像时，即可使用本技能：

| 要素 | 说明 |
|---|---|
| 学段 | 初中任意年级（六/七/八/九年级期中、期末） |
| 输入材料 | ① 试卷文件夹（多份原卷 + 解析版 docx）；② 年级与考型（如"八年级上学期期中"） |
| 典型内容 | 知识体系总览、选择题/填空题/简答题专项拆解、压轴题精讲、跨卷母题、易错点清单、AI 变式题库 |
| 用户诉求 | "出一份学生能直接用的复习资料：公式全部 LaTeX、引用真题一律卷名+题号、讲考点必附完整原题、正文零元信息" |

典型触发指令示例：

> 这是八年级上学期期中试卷文件夹（原卷+解析版），按 math-exam-review-report 出一份《八年级期中考点梳理报告》。

## 🚀 使用方法（工作流概览）

技能按以下 5 个阶段自动执行，完整细节与全部命令见 [SKILL.md](SKILL.md)：

| 阶段 | 内容 | 关键点 |
|---|---|---|
| 1. 资料清点 | 逐卷登记（学校/区/满分/解析版），分配内部编号并建卷名映射；pandoc 批量转 Markdown + 提取题图 | 考试范围不同的卷**单独分组**，禁止混合统计 |
| 2. 逐题数据库 | 逐卷逐题人工判读录入（题型/分值/考点编码/难度），生成 questions.csv + stats.json | 题组总分未标注逐题分值时记 None，**禁止虚构** |
| 3. 撰写内容源 | 按定稿模板写七部分结构；每道引用真题执行"三查"：题号核对、题干选项完整（图片公式必须读图转写）、答案重算 | 动笔前必读 references/ 两份规则文档 |
| 4. Word 生成 | pandoc 转 docx（LaTeX → OMML）+ style_docx.py 后处理（页眉/空段落间隔/题目条目间隔/图片限宽/公式后标点/表格样式） | 页眉「Oli教室专用」每页必带；题目间换行 1 行自动插；题图默认限 6×6cm |
| 5. 质检闸门 | 10 项清单：`$` 配对、禁用字面 grep 归零、TXX 残留、图片/公式数量、页眉存在…… | 任何一项不过必须修复重生成，禁止带病交付 |

### 输入 / 产出

```
输入                                产出
──────────────────────────        ─────────────────────────────────────
试卷文件夹（原卷+解析版 docx）───▶   {年级}考点梳理报告.docx（LaTeX 公式原生排版）
年级与考型                 ───▶    questions.csv（逐题数据库）
                                   stats.json（考点覆盖率/难度分布统计）
```

## 🔧 环境依赖

- **pandoc**（`brew install pandoc`，Markdown → docx 的公式转换核心）
- **Python 3 + python-docx**（运行 `scripts/style_docx.py` 样式后处理）
- 中间产物写入工作区 `.workbuddy/` 目录（不在用户工作区根目录新开文件夹）

## ⚠️ 重要说明

1. **定稿模板只读**：《七年级期中考点梳理报告.docx》是冻结的模板基准，任何情况下不得修改。
2. **学生正文零元信息**：版本号、"LaTeX 排版"、"附原题"、图片来源、数据库说明等一律禁止出现——只写知识点干货；已删除的内容严禁在任何后续版本加回。
3. **引用规则**：正文一律"卷名 + 题号"（学生不知道 TXX 编号）；讲考点/陷阱必须附完整原题且题目与答案分段；表格中不放原题。
4. **结论可追溯**：一切"高频/必考"表述必须能回溯到逐题数据库与原卷题号；区分"已考查事实 / 统计规律 / 备考推断"。
5. **换年级适配**：只需替换试卷文件夹、卷名映射与分组、考点编码体系、内容源正文四样；格式规则、模板、脚本、质检全部复用（见 `scripts/build_db.py` 头部适配指南）。

## 🐛 已知踩坑点（节选）

SKILL.md 与 references/format-rules.md 中记录了完整的 25 条「错误 → 用户反馈 → 正确处理」，包括：

- 用 Unicode 上标（x²、aⁿ）糊弄公式——必须全部走 LaTeX 渲染；
- 原卷选择题的选项是图片公式，转写时整个丢失——必须逐张读图转写并核对四选项齐全；
- "附完整原题""逐条附原题"这类元描述写进正文——用户要的是题目本身，不是附题声明；
- 引用题号未逐一核对导致张冠李戴——每道引用题 grep 原卷核对；
- RGBA 透明底题图在某些渲染器显示全黑——先压平到白底再嵌入；
- 手工誊抄目录清单漏卷——清单必须脚本生成，转换前后打印"目录数 = 处理卷数"对账；
- 系列卷解析版与原卷版串卷、题号错乱——锚点题抽查对质，无法对位的卷剔除统计；
- 条目先放答案再放题图、题图集先图后题——顺序固定为"题目 → 题目图片 → 答案 → 解析"，任何情况下题目都在图前，check_content.py 自动拦截；
- 题目条目之间没有空行——所有有题目的地方每题结束换行 1 行，style_docx.py 自动插；
- 题图按原生尺寸插入过大——默认限 6×6cm，超限等比缩小；
- 图片被插成"图+图注"的标题样式结构——pandoc 禁用 implicit_figures，图片以普通段落插入、可自由移动；
- 修改交付 Word 时整卷重写覆盖用户手工改动——一律 XML 手术精修、只动用户点名的部分；
- ……
